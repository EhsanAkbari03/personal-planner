# Habito – AI Personal Planner

An AI-powered personal planner that allows users to manage
tasks, reminders and habits using natural language.

## Features

- Natural language task creation
- Habit management
- Reminders
- Password reset
- Persian language support
- PostgreSQL database
- Gemini/Groq LLM integration
- FastAPI backend

## Architecture

User → FastAPI → LLM → Tools → PostgreSQL

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- Gemini / Groq
- REST API
- Docker
- Git/GitHub
